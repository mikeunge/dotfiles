# fonts

> I currently use "GeistMono" as my primary font for eg. kitty.

To install the fonts, create the `.fonts` folder in your home directory, copy
the fonts in there, et voila - you now have patched (nerd-) fonts

## Installed fonts

- [Fira Code Nerd Font](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/FiraCode)
- [Fira Mono Nerd Font](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/FiraMono)
- [Geist Mono Nerd Font](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/GeistMono)
